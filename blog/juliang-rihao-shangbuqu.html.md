# 巨量引擎日耗上不去？先查这 5 个地方

> 余额充足、计划正常，但日耗就是上不去——这不是投放技巧问题。我自己账户 41 个授权账户里 32 个零消耗，单个账户 40 个项目里 35 个是空壳。附完整排查顺序与三个真实原因。

- 来源：投流舱 AdCabin（https://adcabin.yuhuakeji.com.cn/）
- 发布日期：2026-09-18
- 阅读时长：约 8 分钟
- 数据说明：数据来自我方自营微信小程序广告账户，已脱敏

账户余额一千多，计划状态一切正常，日耗却只有十几块。我盯着后台看了很久，一直以为是出价太低、定向太窄。直到把所有授权账户拉成一张表，才发现真正的原因在更上面一层——绝大多数字段不是「跑不动」，而是「根本没在跑」。

## 先看症状：你的账户属于哪一种

「日耗上不去」这句话背后至少有三种完全不同的病。混在一起看，就会一直修错地方。

| 表面现象 | 真实原因 | 该修哪里 |
|---|---|---|
| 余额充足，但消耗极低 | 计划建得不完整，投不出去 | 账户结构层 |
| 计划在跑，但量级很小 | 出价没竞争力 / 关键词池太小 | 出价与词包 |
| 消耗忽高忽低，不稳 | 素材老化，系统找不到稳定转化人群 | 素材层 |

- **78%** — 授权账户零消耗（41 个账户里 32 个）
- **87%** — 空壳项目占比（40 个项目里 35 个废弃）
- **¥13.69** — 单账户日耗（余额 ¥1,339 却花不出去）
- **¥44** — CPM（量级 = 钱 ÷ CPM）

## 原因一：项目建了，单元没建（最常见）

巨量引擎是三层结构：项目 → 单元 → 素材。很多人（包括我自己）批量建计划时只建到项目层就停了——后台里项目状态显示 ENABLE，看起来一切正常，但没有单元就等于没有可投放的实体，消耗永远是 0。

我那个主力账户里，40 个项目有 35 个是废弃的空壳项目。它们安静地躺在列表里，占着位置，吃掉了我的注意力，还让我误判了「我已经建了很多计划」。

> **要点｜怎么快速确认**
> 在 竞价投放 → 搜索 → 单元 里看单元列表。
> 如果单元数远少于项目数，差额就是空壳。
> 更直接的办法：看项目的 消耗 字段，长期为 0 的基本都是这个原因。

## 原因二：关键词池本身就太小

搜索模式下，量级的上限由关键词池的搜索量决定。我在搜索侧铺了 334 个关键词，听起来不少——但平均到每个词，每天的曝光不到 1 次。

```
量级 ≈ 关键词池搜索量 × 你的竞价胜率
334 个垂直词 ÷ 总曝光 5,830 = 每词每天不到 1 次曝光
```

而且这些词的搜索量本身就极低。这意味着：不是你的出价不够高，是这个词池里根本没有那么多人在搜。这时候提出价，只会把成本推高，量还是上不来。

> **注意｜⚠️ 一个反直觉的结论**
> 在词池过小时提出价，等于用更贵的价格去抢同样少的流量。
> 正确做法是先扩词（长尾词、问答词、场景词），把池子做大，再谈出价。

## 原因三：钱没少花，是 CPM 太贵

算一笔账就清楚了。假设你想把日展示量做到 3,000，在 CPM ¥44 的情况下需要多少钱：

| 目标日展示量 | 需要的日消耗 |
|---|---|
| 312 | ¥13.69（我当时的实际值） |
| 1,140 | ¥50 |
| 2,280 | ¥100 |
| 6,830 | ¥300 |

所以「展示量低」这个问题的答案是一道乘法题：展示量 = 钱 ÷ CPM。钱只有十几块、CPM 又要四十多、词池还很小——三者相乘，必然只有几百次展示。

> **说明｜所以「日耗上不去」有两种截然不同的处境**
> 有钱花不出去：余额充足但消耗低 → 结构问题（本文重点），修完立刻能跑量。
> 钱不够花：预算本来就小 → 这不是问题，是按比例的正常结果。
> 先分清是哪一种，再决定要不要「想办法提量」。

## 完整排查顺序（照着做）

1. **先看单元数，不看项目数** —— 在单元列表里数一遍。单元数远少于项目数 → 大量空壳项目，先补齐单元。
2. **看关键词池的真实搜索量** —— 把关键词按曝光排序，看有多少词是长期零曝光的。占比超过一半说明池子太小。
3. **算一遍「展示量 = 钱 ÷ CPM」** —— 用当前的日消耗和 CPM 算出理论展示量，和实际值对比。对得上就说明没有异常，只是量级本来就小。
4. **检查素材挂载时间** —— 素材超过 2 周没更新，系统会逐渐减少分配。这会让消耗变得不稳定。
5. **最后才动出价** —— 以上四步都确认无异常，才轮到调出价——而且要用小步试（比如 +10%），观察 3 天。
## 一个必须提醒的坑：有些计划根本改不了出价

如果你想「提出价试试」，先读计划的投放类型。极速智投（自动投放）的计划，出价由系统托管——调接口会直接返回：

```
自动投放单元不能包含出价参数
```

周期稳投（delivery_type=DURATION）同样不支持改价。这类计划想提量，只能从素材侧下手——补新素材、扩标题数量，而不是硬改出价。

## 常见问题

### 巨量引擎日耗上不去，最可能是什么原因？

最常见的是账户结构不完整：只建了项目没建单元。巨量是「项目 → 单元 → 素材」三层结构，缺一层就没有可投放实体，消耗永远是 0，但项目状态仍显示正常。其次才是关键词池过小和出价无竞争力。

### 余额充足但消耗很低，是账户被限流了吗？

多数情况不是限流，而是结构或竞价问题。建议按顺序排查：单元数是否齐全、关键词池真实搜索量、用「展示量 = 日消耗 ÷ CPM」验证是否属于正常量级、素材挂载时间是否过久。四项都无异常再考虑出价。

### 提出价能提升日耗吗？

未必，且可能适得其反。如果关键词池本身搜索量很低，提出价只是用更贵的价格抢同样少的流量，成本上升而量不变。另外极速智投和周期稳投类型的计划不支持修改出价，调接口会返回「自动投放单元不能包含出价参数」。
