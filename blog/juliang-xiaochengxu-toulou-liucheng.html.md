# 巨量引擎投放微信小程序完整流程：从开户到广告上线
> 巨量引擎投放微信小程序的全流程实操：开户与对公验证、升级版工作台、成员与资产管理、橙子落地页搭建、搜索项目创建（优化目标选激活）、单元与文案素材配置。含每一步的关键选项与易错点。


作者：**投流舱 AdCabin**
 2026-09-18
 阅读约 **14 分钟**
 类型：**全流程实操**



 这是我们把一个小程序从零投上巨量引擎的完整过程记录——开户、对公验证、升级版工作台、
 橙子落地页、项目与单元配置，一步不落。
 **每一步都标注了关键选项和当时卡住我们的地方**，你可以照着走一遍。

> **先说一个前提：这件事现在比前两年容易**

> 抖音广告支持跳转微信小程序，**无需特殊认证**。同时小程序本身的开发成本也降了——
 认证费一年几十块，云开发资源前 6 个月基本免费。
 对个人开发者来说，以前卡住的几个环节今年差不多都被对冲掉了。

## 一、开户：注册、主体信息、资质与对公验证

1

#### 注册账号

打开巨量引擎官网 `https://www.oceanengine.com/`，右上角点「立即开户」，用手机号注册。

2

#### 填写主体信息

手机号注册后需要填：公司名称、统一社会信用代码、法定代表人/经营者姓名、法定代表人身份证号，
 以及**推广行业**。

行业我们选的是 工具软件类 - 实用工具。这一项建议按小程序的实际用途选，
 不要为了过审随便选——后面账户的类目和可用能力会跟它关联。

> **⚠️ 个体户还是企业？**

> **注册身份需要个体户或企业的营业执照。**纯个人身份注册之后只能投抖加，
 无法做搜索投放。这一步决定了你后面能不能选到「微信小程序」这个营销产品。

3

#### 资质验证

提交公司营业执照照片。

4

#### 对公验证

有多种方式：法人人脸识别、对公打款等。

我们走的是**人脸识别**：填写法人身份证号 + 手机号 + 邮箱，
 人脸识别方式可选抖音或支付宝——**建议选支付宝**，流程更顺。

发送验证码并填写后，下一步会给出对公验证二维码，法人扫码完成人脸识别，开户成功。

## 二、升级版工作台：还要再验证一次

这里是最容易卡住的地方：**开户成功不等于能用。**
 因为巨量引擎工作台正在升级，你还需要进入升级版再验证一次。

1

#### 进入升级版并按提示验证

点击「进入升级版」，按提示操作。如果你注册用的手机号名下关联了多家公司，
 系统会让你确认**用哪一家作为这个手机号下的超管主体**、是否关联等，按需选择。

2

#### 填写组织信息

需要填：组织名称、组织联系人姓名、手机号、邮箱。

这几个字段比较宽松——**人员不必是法定代表人，组织名称可以简写，联系人可以填别名，中英文皆可**。

3

#### 再一次对公验证

需要重新填写公司名称、营业执照号、法人相关信息（和第一次填的一样），步骤与前面第 4 步基本相同。

4

#### 进入工作台并选择「巨量营销」

对公验证通过后进入升级版工作台，在 巨量引擎营销服务 里选择「巨量营销」。

> **💡 概念澄清：工作台 ≠ 账户**

> 这是新手最容易混淆的一点：**工作台和可操作的广告账户是两个不同层级的概念，账户从属于工作台**。
 一个工作台可以管理 20 个账户。所以「我注册了」不等于「我能投了」——
 要看你操作的是哪个账户。

## 三、成员管理：添加成员与角色

管理 → 管理中心 → 成员管理 → 当前组织成员 → 添加成员

需要填三块信息：

| 填写项 | 说明 |

|---|---|

| 选择所在组织 | 下拉选取，一般具有唯一性 |

| 成员信息 | 一般选择成员手机号；成员姓名可用代称，中英文皆可 |

| 成员角色 | 选择该成员在本组织承担的角色 |

**提效技巧**：如果多个成员角色相同，可以在成员信息里点「继续添加」，
 先批量录入成员，再统一点选角色；只有角色各不相同时才需要逐个录入。

> **⚠️ 记得提醒成员在 48 小时内确认邀请**

> 提交后会弹出「成员信息确认」窗口，确认无误后点「继续提交」。
 之后相关成员会收到短信，**直接点短信里的链接打开浏览器即可同意邀请**。
 **邀请有时效（48 小时），过期要重新发。**
 刷新页面可以在「当前组织成员」列表里看到邀请进度。

## 四、资产管理：把微信小程序加进来

资产 → 小程序/小游戏 → 微信小程序 → 添加资产 → 添加升级版小程序

按流程填写相关信息：

- 「选择主体」卡片是下拉选取，一般具有唯一性

- 根据小程序具体用途选择「小程序类型」，并在下拉列表中选「细分分类」

点「下一步」后会回到「微信小程序」页面，成功添加的小程序会显示在卡片列表上。

> **⚠️ 加完看不到？可能是版本问题**

> 因工作台升级，如果资产是通过「**导入微信小程序**」方式添加的，
 可能需要切换「**资产版本**」才能看到它。别以为没加成功就重复提交。

## 五、搭建橙子落地页

这一步是把小程序变成可投放的落地页。路径：

素材 → 橙子落地页 → 新建橙子落地页 → 选择账户 → 新建 → 使用空白模板新建

弹窗里「账户类型」选 **巨量营销**，「账户」在下拉列表中选取。之后会跳转到橙子建站。

关键步骤：

1

#### 改站点名称

点「新建站点」旁边的编辑图标即可修改橙子落地页名称。

2

#### 插入微信小程序组件

组件 → 微信小程序 → 基本样式，选第一个样式。

3

#### 配置小程序模块

选中模块后在右侧补信息：「小程序」选择**广告账户直属团队小程序**；
 「内容设置 → 小程序简称」按需填写；「内容设置 → LOGO 图」点「替换」，
 可用已存在的图片或本地上传。

4

#### 设计三段式布局

选中组件，在上方插入空白模块，做成「文字描述 + 图片 + 微信小程序」的三段结构。

然后用 文本 → 简单文本 填充文案；中间模块用
 模块背景 → 使用图片 放图。

5

#### 调整与发布

选中模块后上下各会出现一个标识，可以拖拽调整位置，文本框也能移动。
 调好后点右上角「保存并发布」，勾选同意后点「发布」。
 出现预览页面就说明落地页建好了。

## 六、创建搜索项目

回到工作台，路径：

竞价投放 → 搜索 → 项目 → 新建项目

> **小技巧：先给账户改个名字**

> 一个组织下可以建多个账户，**账户默认全是数字，很难分辨**。
 建议先在 账户管理 → 账户信息 里改账户名称并上传头像（需等待审核）。
 账号建好后系统会自动生成一个账户，需要更多就点账户名称下的复制图标新建。

新建项目时需要按次序填这些内容：

| 配置项 | 选择 |

|---|---|

| 营销目的 | **小程序** |

| 营销场景 | 默认「短视频 + 图文」 |

| 营销产品 | **微信小程序** → 弹窗里选对应小程序，点「使用」 |

| 优化目标 | **激活** |

| 投放模式 | 默认「极速智投」，不用改 |

| 自定义关键词 | 可手动编辑，或上传按模板填好的文档批量导入 |

| 用户定向 | 根据小程序用户定位选择 |

| 第三方监测链接 | 填写「有效触点」（需自建回传） |

| 项目名称 | 按自己的规则命名，便于后续管理 |

填完点「保存并新建单元」，页面会跳到「单元」。

> **⚠️ 注意：默认投放模式是「极速智投」**

> 这个模式开出价由系统托管。**后续你想手动改出价是改不了的**——
 接口会直接拒绝（「自动投放单元不能包含出价参数」）。
 所以如果一开始就打算精细控价，在这一步就要留意投放模式的选择。
 这也是我们后来在 API 层撞到的坑之一。

## 七、配置投放单元

1

#### 投放身份

选择「抖音号」——**需要先完成抖音号授权**，否则只能选「账户信息」。

2

#### 基础素材

在「单元素材 → 基础素材」里上传视频素材。

3

#### 文案素材

选「批量添加」，在弹窗里复制粘贴文本，**最多 10 条**，点确认。

非新建账户也可以直接从「标题库」里挑。为了保证投放效果，
 **建议把 10 条标题选满**——系统会从中做轮换优选，条数太少可测试的组合就少。

4

#### 落地页

点「选择」→「我的落地页」→ 勾选前面建好的橙子落地页 → 确定。

5

#### 产品信息

填写产品名称、添加产品主图、填写产品卖点。
 **卖点输入文本后按 Enter 就能变成一个标签**，建议多写几个。

6

#### 单元名称并保存

按规则命名后点「保存并关闭」，页面跳回「竞价投放」。

之后在 竞价投放 → 搜索 → 单元 里可以看到新建单元的状态。
 **新建单元需要审核**：有问题会给审核建议，在「操作」里选「编辑」修改；
 没问题则状态显示「投放中」。

## 八、提效：复制已有单元快速新建

同一账户下要建结构类似的广告，不用从头填：

1. 在 竞价投放 → 搜索 → 单元 列表里选一条，操作里选「复制」

2. 会直接进入「项目」页面，**内容已经填好**，只需微调出价（项目 → 投放模式 → 出价）和项目名称

3. 点「保存并新建单元」，跳到「单元」页面

4. 按前面的步骤调整单元素材、修改单元名称，保存并等待审核

这是批量铺计划时最省时间的做法——**尤其适合「复制跑量计划」这个动作**。

## 九、容易卡住的 6 个点

| 现象 | 原因与处理 |

|---|---|

| 注册后投不了搜索 | 用了纯个人身份。需要个体户或企业营业执照，否则只能投抖加 |

| 开户成功但功能不全 | 没进升级版工作台验证。开户和升级版是两次验证 |

| 添加的小程序看不到 | 可能是「导入微信小程序」方式，需要切换「资产版本」查看 |

| 成员一直没生效 | 邀请短信要成员在 48 小时内点链接同意，过期要重发 |

| 出价改不了 | 投放模式是「极速智投」，出价由系统托管。要控价得在项目阶段就选对模式 |

| 计划建了但不消耗 | 很可能只建了项目没建单元。巨量是「项目 → 单元 → 素材」三层结构，缺一层就跑不起来 |

> **最后一条最重要**

> 「只建项目没建单元」是我们踩过的真实坑：账户看起来一切正常、项目状态是 ENABLE，
 但消耗永远是 0。**排查零消耗账户时，「有没有单元」应该是最先检查的一项。**
 这个坑详见我们另一篇文章。
