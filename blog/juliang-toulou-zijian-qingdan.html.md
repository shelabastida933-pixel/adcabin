## 为什么「先自检」比「先优化」省钱

巨量引擎的投放问题分三层：账户结构层 → 投放执行层 → 承接链路层。这三层的修法完全不同，成本也差一个量级。

结构层的病（项目没单元、计划是空壳）花十分钟就能修，但它表现出来的样子和「出价太低」一模一样；而链路层的病（回传没通）会让所有投放优化都变成无用功——你优化的是一个看不到结果的系统。

所以自检的顺序必须是从下往上：先确认链路通不通，再看结构全不全，最后才轮到出价和素材。顺序错了，钱和时间就都花在了不需要修的地方。

- **78%** — 授权账户零消耗（41 个账户里 32 个）
- **40%** — 预算被零激活素材吃掉（42 个素材里 28 个零激活）
- **2.03%** — 实际激活率（点击率 11.10% 属正常水平）
- **0** — 小程序 ROI 系列指标（回传链路没通）
- **24%** — 消耗集中在不转化人群（41–50 岁：0 个转化）
- **35 个** — 空壳项目（单账户 40 个项目里的废弃项）

## 自检只用到 4 个入口

不用装工具、不用接 API。后台里这 4 个地方，够把 6 种病征全部查一遍。

| 入口 | 看什么 | 用来判断 |
|---|---|---|
| 账户列表 | 每个账户的消耗字段（近 7 天） | 空转症 |
| 项目 / 单元列表 | 项目数、单元数、素材数三者是否对得上 | 僵尸症、空转症 |
| 素材报表（按素材拆） | 消耗 ÷ 激活，找出激活数为 0 的素材 | 黑洞症 |
| 数据报表（按年龄等维度拆） | 各维度的消耗占比与激活成本 | 错位症、漏桶症 |

`竞价投放 → 报表 → 自定义报表 → 勾选「消耗 / 激活数 / 激活成本」并加年龄维度`

## 6 种病征速查表（附阈值）

下表阈值一列写的是我方 41 个真实账户的实测值，不是行业标准，但可以作为「是否已经病到需要处理」的参照。

| 病征 | 一句话症状 | 实测阈值 | 该修哪一层 |
|---|---|---|---|
| 空转症 | 余额充足，日耗却上不去 | 零消耗账户 78% | 账户结构层 |
| 黑洞症 | 素材安静地把预算花完，零转化 | 零激活素材吃掉 40% 消耗 | 素材层 |
| 漏桶症 | 点击正常，激活率极低 | 激活率 2.03%（正常 5~10%） | 承接链路层 |
| 僵尸症 | 项目状态 ENABLE，消耗永远是 0 | 40 个项目里 35 个空壳 | 账户结构层 |
| 错位症 | 钱稳定地花在不转化的人身上 | 41–50 岁占 24% 消耗 / 0 转化 | 定向层 |
| 断链症 | 所有 ROI 指标都是 0 | ROI 恒等于 0（不是接近 0） | 回传链路层 |

> **注意｜⚠️ 先分清「低」和「零」**
> ROI 很低 → 多半是投放效率问题，优化出价与素材有意义。
> ROI 恒等于 0 → 先怀疑链路，不要在投放端浪费预算。
> 同理：激活成本高 ≠ 激活数为 0。前者优化，后者是纯浪费。

## 逐条自查：6 种病征的判断方法

### 病征一｜空转症：账户根本没在跑

算一下零消耗账户占比：近 7 天消耗为 0 或接近 0 的账户，占你全部授权账户的比例。超过 30% 就该往下查了，我这边是 78%。再对比一下「账户余额」和「实际消耗」——余额充足却花不出去，是最典型的信号。

详解：巨量引擎日耗上不去？先查这 5 个地方

### 病征二｜黑洞症：素材在安静地烧钱

把素材报表按 消耗 ÷ 激活 排序，重点看激活数为 0 但消耗不为 0 的素材。它们不会报警，在后台里和正常素材长得一模一样。我这边 42 个素材里有 28 个零激活，吃掉了四成消耗。

详解：素材零激活怎么办：怎么找出在烧钱的素材

### 病征三｜漏桶症：问题不在投放端

看漏斗：点击率正常但激活率极低，就是漏桶。我这边点击率 11.10% 属正常水平，激活率却只有 2.03%，而正常水平应该在 5~10%。这时候加预算买到的还是同一个 2%——等于把钱倒进漏水的桶。

详解：激活率低怎么办：正常范围与 3 个真实原因

### 病征四｜僵尸症：一堆计划在睡觉

在项目和单元列表里看三层数量是否对得上：项目 → 单元 → 素材。缺任何一层，消耗就永远是 0。我主力账户里 40 个项目有 35 个是废弃空壳，它们安静地占着位置，还让我误判了「我已经建了很多计划」。

详解：项目零消耗怎么办：建了项目没建单元

### 病征五｜错位症：钱花在对的人身上，也花在错的人身上

在报表里加年龄、性别等维度，算每个维度的激活成本而不只是消耗占比。重点抓两类：消耗占比高但激活数为 0 的（纯浪费，可直接排除），和消耗不高但激活成本极低的（应加量）。我这边 41–50 岁人群占了 24% 消耗，贡献 0 个转化。

详解：人群错配：24% 的预算花在了零转化人群上

### 病征六｜断链症：所有 ROI 都是 0

这一条要放在最后查，但它最该被最先排除。核对回传事件是否与「优化目标」匹配、回传 URL 的占位符有没有被正确替换、服务端有没有真的收到回传请求。链路不通时，模型学不到谁会付费，量自然起不来。

详解：所有 ROI 指标都是 0：这是数据链路问题

## 30 分钟自检流程

按这个顺序走，每步都给一个明确的结论，不要跳步。

0. **先排链路（5 分钟）** —— 确认回传是否通、ROI 是否为恒 0。链路不通，后面全部免谈——先修链路，别急着动投放。
1. **查账户结构（5 分钟）** —— 统计零消耗账户占比、项目/单元/素材三层数量是否匹配。找出所有空壳项目并清理。
2. **拉素材层激活成本（8 分钟）** —— 按「消耗 ÷ 激活」排序，标出零激活素材与低激活成本素材。零激活的直接停，低成本的加量。
3. **加维度拆人群（7 分钟）** —— 按年龄/性别拉近 30 天数据，算各维度激活成本。先排除零转化人群，再考虑收窄。
4. **算漏斗（5 分钟）** —— 点击率 vs 激活率。点击正常而激活极低，说明要修承接端；两个都低才回到投放端。
## 查完之后：先修哪一个

同时查出多个病征是常态，指望一次全修完通常会失败。按这个顺序，每一步都能在 3 天内看到数据变化。

| 优先级 | 判断依据 | 先做什么 | 为什么排这个位置 |
|---|---|---|---|
| 1 | ROI 恒等于 0 | 先通回传链路 | 链路不通时，任何投放优化都无法被验证 |
| 2 | 零激活素材占比高 | 停掉零激活素材 | 零风险、立即省钱，且不触发系统重新学习 |
| 3 | 空壳项目 / 零消耗账户多 | 补单元、清空壳 | 十分钟的活，直接决定钱能不能花出去 |
| 4 | 存在零转化人群 | 排除（不是收窄） | 零风险，先拿掉确定性浪费 |
| 5 | 激活率显著低于 5% | 修承接端 | 承接修好后，同样预算的激活数会直接上去 |
| 6 | 以上都正常但成本仍高 | 才动出价与素材迭代 | 这一层才是真正需要长期优化的部分 |

## 三个最容易被漏掉的数字

1. 零转化但消耗不为 0 的人群占比——大部分人只盯「激活成本平均值」，而平均值会把「很贵但有效」和「纯浪费」混成同一个数。
2. 激活数为 0 的素材消耗总额——这是可以直接省下来的钱，而且停掉它们不会带来任何负面影响。
3. 项目数、单元数、素材数三者的比例——这三个数的关系，比任何单个指标的绝对值都更能说明账户结构是否健康。

> **要点｜自检的纪律**
> 一个数字只在一个入口看：消耗看账户列表，激活成本看素材报表，人群看维度报表。
> 看到一个异常，先问「这会让我少赚钱，还是只是看起来难看」。
> 不要在自检做完之前改出价——改完你就失去了干净的对照基线。

## 常见问题

### 巨量引擎投放自检多久做一次？

建议分两种频率：结构层（空壳项目、零消耗账户、回传链路）每周一次，因为账户结构变化慢且修起来快；素材层与人群层每 3~7 天一次，因为素材会老化、人群分布会漂移。如果刚做完一次大改（大批新建计划或大规模调整定向），改完 3 天内不要重复自检，否则会把系统重新学习期的正常波动误判成问题。

### 没有 API 权限，能自己做这套自检吗？

能。这 6 项全部可以在巨量引擎后台里用手工报表完成，不需要 API：账户列表看消耗，项目/单元列表看三层结构，素材报表按消耗除激活排序，维度报表加年龄性别。唯一麻烦的是账户多的时候要来回切，而且历史数据不好留存对比——这正是我们做跨账户报表自动化要解决的问题。

### 自检发现好几个病征，能一次全修吗？

不建议。一次改太多会丢掉对照基线，改完你无法判断是哪一个动作起了作用。建议按「链路 → 零激活素材 → 空壳项目 → 零转化人群 → 承接端 → 出价素材」的顺序，每一步单独改、观察 3 天再进下一步。前几步大多是零风险动作，可以连着做；一旦进入出价与定向调整，就必须留出足够的观察期。

### 账户诊断和这份自检清单有什么区别？

清单是方法，诊断是有人拿你的真实数据把方法跑一遍。清单能告诉你「该查什么、阈值大概是多少」，但看不到你的具体数字；诊断会直接给出每一项的实际值、判定的病征，以及按优先级排好的修复动作，并指出哪些动作是零风险的、哪些需要 A/B 对照验证。
